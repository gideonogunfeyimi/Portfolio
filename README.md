# Gideon Ogunfeyimi — communications portfolio

A one-page portfolio website for Gideon Ogunfeyimi, Marketing and Communications Coordinator at Teach For Nigeria. It showcases his communications work: publications, campaigns, thought leadership, film, media relations, digital and photography. Colours follow Teach For Nigeria's palette.

## Contents
- `index.html` — the page (annual reports, giving campaign, recruitment campaign, webinar series, films, media relations, digital, press coverage, photography, contact)
- `style.css` — styles
- `assets/img/` — images taken from his PDF portfolio

## Publishing
Static site with no build step. In the repository's **Settings → Pages**, choose "Deploy from a branch", branch `main`, folder `/ (root)`.
